# Movie Ticket Booking System

## Description

A simple Movie Ticket Booking System developed using Python. The system allows users to view available movies, book tickets, view bookings, search bookings, and cancel bookings.

## Features

- Display available movies
- Book movie tickets
- Calculate total ticket price
- View all bookings
- Search bookings by customer name
- Cancel bookings
- Menu-driven interface

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## How to Run

1. Open `movie_ticket_booking.py`.
2. Run the Python program.
3. Select an option from the menu.

## Menu Options

1. Display Movies
2. Book Ticket
3. View Bookings
4. Search Booking
5. Cancel Booking
6. Exit

## Conclusion

This project demonstrates a basic movie ticket booking system using Python data structures, functions, and user input.
